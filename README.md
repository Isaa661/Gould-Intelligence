## Free GitHub Pages setup

1. Create a free GitHub account if you do not already have one.
2. Create a new public repository named `gould-intelligence`.
3. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
4. Open repository **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose `main` and `/ (root)`, then save.
7. GitHub will give you a free URL similar to:
   `https://YOURUSERNAME.github.io/gould-intelligence/`
